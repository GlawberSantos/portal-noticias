## 🚀 Sobre o Projeto

O **TechNews** é um portal de notícias de tecnologia com layout inspirado em grandes portais de conteúdo. O projeto simula uma página editorial completa, com navegação por categorias, seção de destaques, bloco de notícias mais lidas e área de inteligência artificial.

Foi desenvolvido com foco em:
- Estrutura HTML semântica e acessível
- Organização de estilos com CSS modular (pasta `/styles`)
- Uso de assets otimizados (ícones SVG, imagens e logo)
- Layout responsivo para diferentes tamanhos de tela

## 📁 Estrutura do Projeto

```
fullstack_projeto_portal_noticias/
├── assets/
│   ├── icons/        # Ícones SVG (menu, lupa, etc.)
│   ├── images/       # Imagens das notícias
│   ├── Logo.svg      # Logo do portal
│   └── Ads.png       # Banner publicitário
├── styles/           # Arquivos CSS organizados por seção
├── index.html        # Página principal
└── README.md
```
